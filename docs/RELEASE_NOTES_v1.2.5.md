# 古堡禁地繁體中文版 v1.2.5

## 修正

- 翻譯只用於畫面顯示，不再改變腳本的敵人名稱比較。
- 戰鬥初始化使用原始英文識別字分類敵人，修正部分守衛、騎士與骷髏戰鬥誤載
  `002.VGA` 後中止的問題。
- Elvira 1 的內部重新開始存檔名稱同樣改用原始字串，避免譯文改變資源名稱。

## 根因

v1.2.4 以前在 `getStringPtrByID()` 的共用出口無條件套用繁中譯表。這個函式除了
顯示文字，也供腳本 opcode 135 比較物件名稱。英文只差大小寫的兩個名稱在翻譯後
可能成為不同中文，導致敵人分類條件不成立，戰鬥圖片變數保持 0。

## 驗證範圍

- 玩家 v1.2.4 的繁中／英文 log 已證實問題只在翻譯路徑出現。
- Linux 引擎已在 Docker 內重新編譯。
- 三平台封包與實際戰鬥路徑的最終驗證結果記錄於 issue #2 與技術報告。
