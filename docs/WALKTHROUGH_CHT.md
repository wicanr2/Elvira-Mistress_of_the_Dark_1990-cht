# 《古堡禁地》繁體中文攻略

適用於《Elvira: Mistress of the Dark》（DOS／GOG 資料）及本專案的 ScummVM
繁中補丁。本文是依多份英文攻略、官方手冊整理後重新撰寫的流程摘要，不含遊戲
原檔或手冊掃描。

## 操作與存讀檔

- 左欄「房間／物品／武器」切換可操作的物件集合。
- 右欄先選「查看、拿取、使用、開啟、關閉、上鎖、解鎖」等動詞，再點物件。
- `F7`：本補丁的無敵模式；只建議除錯或避免戰鬥驗證被角色死亡中斷。
- `Tab`：地圖。
- `Alt+1`～`Alt+9`：快速存檔；`Ctrl+1`～`Ctrl+9`：快速讀檔。
- 原版捲軸選單也可存讀檔。檔名最多 8 個 ASCII 字元；Return 或數字鍵盤
  Enter 確認。

## 戰鬥方法

戰鬥是即時攻防，不是回合制：

1. 攻擊階段使用右側的 `LUNGE`（刺擊）或 `HACK`（劈砍），也可直接點敵人。
2. 敵人反擊時，依攻擊方向及時使用 `BLOCK` 或 `PARRY`。
3. 格擋成功後會再取得攻擊機會；不要在防守階段持續亂按攻擊。
4. 初期盡快取得軍械庫的長劍與大盾並「使用」裝備；重甲太重，不建議拿。
5. 每場重要戰鬥前存檔。治療資源有限，受重傷時讀檔重打通常較划算。
6. 弩、銀頭弩箭及攻擊法術應留給有特殊弱點或近戰不利的敵人。

## 開局與脫困

1. 進入古堡大門，鐵閘會關閉。
2. 進左側守衛室，劇情會把主角投入地牢。
3. 艾薇拉救出主角後會交付匕首、兩瓶藥劑及木心料理。
4. 裝備匕首，飲用火焰匕首與照明藥劑；木心料理保留作後期治療。
5. 離開地牢後，在馬廄外取乾草。

## 第一輪搜刮與整備

1. 進城堡，上樓後先搜圖書室，取得愛梅達的黑色魔法書。
2. 搜書房，取得木樁與龜背芋；閱讀日記取得戒指線索。
3. 搜酒吧取得苦艾酒，再下樓把魔法書交給艾薇拉。
4. 廚房取得蜂蜜、葡萄酒、隔熱手套；用帆布袋與手套安全帶走熱煤。
5. 請艾薇拉用蜂蜜與乾草調製 Herbal Honey，飲用後較容易辨認材料。
6. 遇到紅衣守衛後進軍械庫，取得長劍、弩與大盾並裝備長劍、大盾。

## 藥草園與二樓

1. 前往花園入口，沿途檢查灌木取得材料。
2. 穿過拱門，在工具棚取得大鎚、銀十字架；檢查桌上盒子並移動種子包，
   取得開門鑰匙。
3. 回到鎖門處解鎖，擊敗兩名修士後進藥草園收集材料。
4. 回城堡二樓，在吸血鬼房間迅速把木樁與大鎚用在吸血鬼身上；取得灰燼及
   衣櫃內的弩箭。
5. 搜查二樓各房間。聖經內藏祈禱卷軸；不要提早使用。櫃子裡另有弩箭。

## 六把金鑰

鑰匙上的拉丁序號不一定等於玩家取得順序，重點是六把都要收齊。

1. **馬廄狼人**：在鐵匠鋪把銀十字架放進坩堝熔化，再放入弩箭製成銀頭
   弩箭；狼人變身後立刻射擊。馬廄牆上的鐵環後藏有金鑰，取完要把鐵環放回。
2. **獵鷹人**：先在靶場練弩並回收弩箭；獵鷹放出時用弩射殺，搜查獵鷹取得
   金鑰與羽毛。
3. **守衛隊長**：回守衛室擊敗隊長；可用火焰匕首法術降低近戰風險。移開告示
   板上的文件取得金鑰。
4. **刑房**：深入地牢，在刑房移走地上的鐵環，取得骷髏與金鑰。火鉗必須先
   放進帆布袋再帶走，直接碰觸會死亡。
5. **送菜升降機**：用薊、蒲公英與火焰花調製照明法術，照亮廚房送菜通道，
   讓艾薇拉進入並帶回金鑰。
6. **無敵騎士**：城牆上的騎士不適合近戰，用弩把他射落。之後取得生鏽鑰匙，
   進井下水道找回騎士屍體上的最後一把金鑰；缺氧警告出現時立刻浮上水面。

## 廚師、迷宮與十字軍之劍

1. 從地牢帶回鹽，對廚房內的廚師使用，讓艾薇拉重回廚房。
2. 進花園迷宮前多存檔。哥布林可能點燃主角或偷走道具，優先使用弩與法術。
3. 對巢穴黑暗中的眼睛持續使用弩或法術，直到眼睛消失，再進去取得艾薇拉的
   戒指。
4. 在教堂祭壇十字架放入戒指，進入密道取得王冠。
5. 對壁畫使用祈禱卷軸，再把王冠放到骷髏頭上，取得十字軍之劍並裝備。

## 地下墓穴、水道與寶箱

1. 在地下墓穴對灰色怪物先攻擊手臂，再砍頭；在其守衛的棺材取得生鏽鑰匙。
2. 把刑房取得的骷髏放進空棺並關上棺蓋。
3. 開啟會淹水的棺材後迅速下潛，用生鏽鑰匙開水下閘門；反覆浮上換氣。
4. 找到墜落騎士的屍體並取得第六把金鑰。
5. 使用火鉗夾著熱煤點燃大砲，炸開塔樓區域並找到六鎖寶箱。
6. 六把金鑰全數開鎖後取重要卷軸；處理危險匕首前先把背包放下並存檔。

## 最終準備

- 收集材料時多點灌木、植物、洞穴、骷髏及容器；法術材料數量有限。
- 常備治療、攻擊與防禦法術，但普通守衛盡量用長劍／十字軍之劍解決。
- 最終區域前保留獨立存檔，不要覆蓋唯一進度。
- 某些怪物有固定弱點；近戰完全無效時，不要硬磨，改查弩、特殊箭或法術。

## 本專案驗證狀態

- 已實測：繁中介面、方向與動詞點擊、捲軸存檔 Return、讀檔 KP Enter。
- 已實測：載入玩家存檔後可繼續移動至 NPC 對話，未出現 `sprite id 0`。
- 已實測：由玩家 slot 4 正常探索、開門遇到藍甲守衛；右側紅色戰鬥命令出現，
  交替操作 `LUNGE/HACK/BLOCK/PARRY`，第 44 次操作後敵人消失並恢復探索介面。
  程序持續存活，log 未見 `sprite id 0`、`001.VGA`、`002.VGA`、SIGSEGV 或
  `error:`。這證明目前 Linux 工作樹版本可完成一般守衛戰；不代表所有特殊敵人、
  Boss 或三平台實際封裝均已驗證。
